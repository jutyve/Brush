# 🖌️ Brush

A small, interactive painting website where you can draw freely with your mouse.

Built with **HTML, CSS, JavaScript, Vite, and Anime.js**.

## 🚀 Getting Started

### Prerequisites

Make sure you have **Node.js** installed on your computer.

### Installation

1. Clone the repository:

```bash
git clone <YOUR_REPOSITORY_URL>
cd <YOUR_REPOSITORY_FOLDER>
```

2. Install the required dependency:

```bash
npm i animejs
```

3. Start the development server:

```bash
npx vite
```

4. Open the URL shown in your terminal, usually:

```text
http://localhost:5173/
```

And that's it. **TADAA!** 🎨

## ✨ Features

* 🖱️ Draw with your mouse
* ✨ Animated brush strokes
* 🎨 Interactive painting experience
